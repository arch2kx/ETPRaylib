Eden Treaty Pandemonium
=======================

To play, double-click ETP.exe.

Keep ETP.exe and the assets folder together - the game loads assets by
relative path.


Adding it to your Start Menu
----------------------------

Double-click "Install Shortcut.bat". It creates Start Menu and Desktop
shortcuts pointing back at this folder.

To undo, open a Command Prompt here and run:

    "Install Shortcut.bat" -Remove

The shortcuts point at this folder, so don't move the game afterwards -
re-run the script instead if you do.


SmartScreen
-----------

The game isn't code-signed, so Windows may show a "Windows protected
your PC" warning the first time. Click "More info", then "Run anyway".
